酒店版话务台配置手册

一、配置网关​

1、登录网关​

网关接通电源，连接好网络，获取网关初始IP地址，登录网关
登录默认密码是：admin
举例如下图所示：

2、基本设置---网络​

连接方式下拉选择“固定IP地址”，IP地址填写网关IP地址； 例如：192.168.6.137，下面的字段要与网关字段相同，然后点击“保存”

3、外线设置---SIP外线​

举例：
中继类型：直连；
SIP服务器是阿尔卡特的IP地址，如：192.168.6.39
号码：5550，用户名：5550，
并发通道数为10（可以自己设置），密码：自己常用密码即可
确定保存

参考5550，再“新增”一条号码为“5551”、“5552”和“556”的SIP线路，并发通道数：10
5550用于叫醒、5551用于房态迷你吧，5552用于语音信箱，556用于话务台
（并发通道数根据需求设置即可）
如下图所示：

4、基本设置---拨号规则​

外呼规则：
下拉选择：“SIP外线顺选”，然后在右边勾选SIP外线线路5550，设置好保存数据

5、应用服务---API​

服务器地址是安装中间件服务器IP地址加端口号8989
如：192.168.6.27:8989

设置下面的API功能开关
点击下面的SIP外线，把来电应答后控制和状态监控都选上，然后保存

6、基本设置---语音管理​

有话务台功能时，需要上传录音提示文件，选择上传欢迎词，把录好的文件放在C盘根目录下，点击上传，文件上传成功即可（提示：文件大小最好不要超过2M）上传uaer_blank和uaer_blank2
上传成功即可（防止拨打接入码打入话务台，无法呼入）

7、分机设置---IP分机​

新建一个IP分机的号码修改为：8888
使用IP鉴权时的IP地址修改为：1.1.1.1（目的是使该分机号永久在线）
设置后当阿尔卡特上的分机号码无人接听或忙线时即会转移至此语音信箱
按照创建8888IP分机的步骤重新创建一个话务台号码8886
（8886在网管上配置好后，同时也要在话机上进行注册）

再点击“设置”，按下图修改

8、高级设置---路由表（语音信箱）​

添加以下内容，其中IP地址替换成华为eSpace的IP地址
举例如下：
FXS *99 ADD -#
FXS *99x ROUTE IP 192.168.6.130:5060
FXS #99 ADD -#
FXS #99x ROUTE IP 192.168.6.130:5060

9、高级设置---功能码（语音信箱）​

若功能码的常用功能导航与路由表中的99重复，请将功能码修改成其它号码
举例：修改成*97

10、应用服务---媒体（语音信箱）​

编解码修改为：G.711U/20（使留言声音更清晰）

11、安全---安全配置​

勾选启用“允许SSH访问”
并把SSH两个访问身份root和operator都设置好访问密码（两个访问身份密码最好一致）
举例如下图所示：

二、配置交换机通讯管理系统​

打开“中间件基础管理系统”所安装的“BillCommon”，并对其进行设置
注意：在打开之前，右键单机“BillCommon”选择“属性”勾选“以管理员身份运行”，操作如下图：

1、服务器设置​

本机信息-IP地址，例如：192.168.6.27（是安装软件的服务器IP地址）
注：此IP地址要与IPPBX地址互联互通
数据库信息-IP地址：localhost，测试连接---成功---保存

2、配置登录页面​

（1）用户名：admin，密码：88888
选上记住密码和自动登录，点击登录

（2）下图为管理端首页面

3、系统设置​

（1）资费参数 运营商设置，默认区号是北京，可以右键修改，下拉列表选择区号或手动输入。例如：

（2）出局码设置 点击中继信息，程序默认是9，需要修改，点击出局码修改，然后保存即可

4、CDR连接​

交换机品牌：Alcatel
交换机型号：SHAlcatel
通讯方式：HTTP Listener
URL：http://服务器IP地址:7788/service/
对端IP地址：阿尔卡特IP地址
对端端口号：80
用户名：api（默认）
密码：api（默认）
（用户名密码在阿尔卡特---PBX---常规设置---API接口设置中查看）

填写完毕后点击保存，启动

5、PMSI连接设置​

端口号：8989 ，与网关端口号一致
IP地址：192.168.6.137 是网关IP地址
用户名：admin
密码：admin（密码如果修改了，在页面也需要修改；）
测试连接---成功---保存 即可

6、网关设置---通讯连接​

端口号：8989 ，与网关端口号一致
IP地址：192.168.6.137 是网关IP地址
用户名：admin
密码：admin（密码如果修改了，在页面也需要修改；）
并发通道数需要和网关设置的一致
测试连接---成功---保存 即可

7、网关设置---网关接口参数​

叫醒，语音信箱和房态迷你吧的语音号码需要和网关中设置的一致；
语音信箱中转接目标号码为语音信箱的分机号码
房间号码需要与酒店实际的房间号码一致
话务台语音号码需要和网关中设置的一致；
话务台日服号码需要与话机中设置的账号一致；
语音排除号码：填写网关SIP外线号码（包括叫醒语音号码，房态迷你吧语音号码，语音信箱语音号码、话务台语音号码） 如在中间件网关设置前缀，需要把相应的前缀填写上
配置好后，点击“保存”按钮

三、配置话务台电话​

1、设置话务台电话​

查看话务台话机的IP地址，点击话机上OK键查看IP登陆配置信息
网址是：话机IP地址
账号：admin
密码：admin
例如：
话机IP地址：192.168.6.73
用户名：admin
密码：admin
然后点击“登入”进入配置页面

2、账号-话机账号​

根据网关中IP分机设置的分机信息，来设置名称和密码
账号信息：与网关设置的分机号码信息必须一致，填写好即可
SIP服务器：填写的是网关IP地址与端口号等信息
配置好“提交”即可

3、功能-远程控制​

点击“功能”里的“远程控制”
允许控制IP列表：填写的是安装话务台的客户端IP地址

4、功能-基本信息​

点击“功能”里的“基本信息”
禁用---送号键（去电盲转功能）
禁用---保留#送号（去电盲转功能）
启用---RFC 2543保持模式，目的是保持音乐

5、功能- Action URL​

设置需要功能的参数；

提示：如果复制失败，系统会自动显示文本供手动复制

注册成功：

http://192.168.1.100:39671/Register.aspx?active_url=$active_url

放下手柄：

http://192.168.1.100:39671/Receive.aspx?state=0&call_id=$call_id

拿起手柄：

http://192.168.1.100:39671/Receive.aspx?state=4&call_id=$call_id

来电：

http://192.168.1.100:39671/Receive.aspx?state=6&remote=$remote&type=1&call_id=$call_id

去电：

http://192.168.1.100:39671/Receive.aspx?state=5&remote=$remote&call_id=$call_id

建立会话：

http://192.168.1.100:39671/Receive.aspx?state=2&remote=$remote&call_id=$call_id

结束：

http://192.168.1.100:39671/Receive.aspx?state=1&remote=$remote&call_id=$call_id

保持：

http://192.168.1.100:39671/Receive.aspx?state=7&remote=$remote&type=1&call_id=$call_id

取消保持：

http://192.168.1.100:39671/Receive.aspx?state=8&remote=$remote&type=1&call_id=$call_id

未接来电：

http://192.168.1.100:39671/Receive.aspx?state=3&remote=$remote

拒绝来电：

http://192.168.1.100:39671/Receive.aspx?state=3&remote=$remote

取消呼出：

http://192.168.1.100:39671/Receive.aspx?state=1&remote=$remote&call_id=$call_id

按照相应参数填写配置就可以

四、阿尔卡特PBX配置​

1、添加网关中继​

登录阿尔卡特PBX网页，找到PBX---中继，点击“新增”，按照如下参数进行填写。

注意：在阿尔拉特PBX---SIP设置---中继设置中的SIP端口号，要与网关中SIP外线账号的SIP服务器端口号保持一致，如下图所示

2、添加呼入路由​

点击阿尔卡特PBX---呼叫控制---呼入路由，点击“添加”按钮新增呼入路由，将新增网关添加到成员中继里，目的地选择分机范围，并在下方按照“分机号-分机号”填写所要使用的分机范围
注意：DID匹配模式要与分机范围进行适配
例如：分机范围：1001-1009
DID匹配模式：5503301-5503309

3、配置呼出路由​

点击阿尔卡特PBX---呼叫控制---呼出路由，点击“添加”按钮新增呼出路由，将新增网关添加到成员中继里，同时将填写好的分机范围中的分机添加到已选分机中
按照如下图所示对拨号模式进行配置

五、话务台客户端配置​

注意：在打开之前，右键单机“交换机通讯管理系统话务台”选择“属性”---“兼容性”---勾选“以管理员身份运行”，操作如下图：

1、服务器设置​

打开话务台客户端配置，首先配置"服务器设置"

服务器地址：填写交换机通讯管理系统服务器IP地址
数据库IP地址：填写交换机通讯管理系统服务器IP地址
点击“测试连接“连接成功之后，保存

用户名：admin；密码：88888；点击登陆即可

进入“话务台”客户端页面

注：酒店版话务台一般不涉及“强插”“强拆”功能，并且企业通讯录一般使用较频繁，可在HotelManagement.exe.configw文件中进行参数修改。修改如下：

取消“强插”“强拆”功能：
add key="DirectoryIndex" value="1" />
企业通讯录置顶：
add key="ForcedHide" value="true" />
